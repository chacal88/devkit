- [important] plugins/openspec/hooks/change-loop.mjs:3289 (runDeclare) and plugins/openspec/skills/ship-change/SKILL.md:60 (stop-review-deadlock row) — The owner's words reach `declare review-round` only as `--param words="<their words>"` on the shell command line; runDeclare parses no `--stdin`, unlike `reply`, which got it so free text with quotes, `$` or backticks never goes through the shell (jira-entry-followups D-5).
