Real-run proof of state-skips-unlocated (design D-8)

Setup: a scratch repository (<scratch>) with `schema: devkit`, the devkit schemas installed, and a roadmap
with one round holding `- [ ] aa` and `- [ ] xx`. `aa` and `xx` were opened with this worktree's
`change-loop.mjs open <id> --script devkit --why doubt --lang en`; then the branch of xx's worktree was
renamed: `git -C <scratch>/.claude/worktrees/xx branch -m xx side`. The folder of `xx` is now only in a
worktree on branch `side`; `aa` stays in its own worktree on branch `aa`.
Deviation from the plan's ids: the plan names the changes `a` and `x`, but `change-loop.mjs open` refuses
a one-letter id (`name-invalid`: NAME needs 2 to 48 characters), so the proof uses `aa` and `xx`.

The "base" section runs origin/main's hooks (`git archive origin/main plugins/openspec`, extracted to <base>);
the "after" section runs this worktree's hooks. Both ran on the same scratch repository, with DEVKIT_* and
GITHUB_* unset. Paths: <worktree> is this change's worktree, <scratch> the scratch repository, <base> the
extracted origin/main plugin.
