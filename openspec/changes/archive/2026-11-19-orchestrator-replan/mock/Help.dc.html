devkit · como usar Esc fecha
Você digita o comando na caixa de texto da conversa, com o pedido junto. O painel só mostra.
Começar um trabalho
/devkit change PROJ-482 Uma tarefa só, pelo código ou pelo link do Jira.
/devkit change o que você quer Uma tarefa só, descrita em texto.
/devkit roadmap O roadmap inteiro, uma change por vez.
/devkit roadmap 3 O roadmap inteiro, com até três changes ao mesmo tempo.
/devkit project nome da fatia Planejar a fundo nas quatro fases. Termina no roadmap.
Acompanhar
/devkit status Onde está cada coisa e o que espera você.
/devkit help Abre este painel.
Quando ele espera você
Responda na conversa, no seu idioma. Se a conversa fechou, chame o mesmo comando de novo: ele continua de onde parou.
