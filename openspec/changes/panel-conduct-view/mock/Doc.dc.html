Configurações do equipamento nos três Control iD, com o motor neutro cortado antes

device feature architecture · contract · ui hardware necessário 18 set 2026

Why

O operador não consegue ver nem alterar as configurações de nenhum Control iD pela nossa tela: os três models do fabricante declarados em controlid.driver.json não têm models[].settings, e nenhuma das três famílias registra a chave settings.

Para mexer em tempo de relé, sensor de porta, alarme, identificação por cartão/face/QR ou idioma, ele abre a interface web do próprio aparelho, exatamente a dependência que a rota única GET/PUT /device/:id/settings existe para matar.

E este é o terceiro dialeto de configuração do repo, depois do ISAPI (Hikvision) e do bio-t (Intelbras)…
